# Bubble-Game
An interactive Bubble Game using HTML, CSS, and JavaScript. 
Implemented random number generation for dynamic gameplay and a timer-based scoring system.
Added a replay feature prompting users to restart or view their final score.
Designed a responsive UI with smooth animations for an engaging user experience.
